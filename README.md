# Chunk Reading Studio v1.2 — 86편 확장판

**GitHub Pages / 모바일 웹 / PWA / 로컬 실행을 위한 HTML·CSS·JavaScript 정적 학습 홈페이지**

이번 버전은 기존 v1.1의 60편 학습 기능을 유지하면서 두 개의 추가 첨부 자료를 통합하고, 연속 듣기 중에도 배속을 변경할 수 있도록 개선한 확장판입니다.

## 1. 포함 자료 및 구성

| 과정 | 원문 | 주요 내용 | 별도 자료 |
|---|---:|---|---|
| Core Reading | 30편 | CEFR B1–B2 기초·중급 직독직해 | 30편 원문 |
| University | 30편 | C1 학술 독해·논증·문법·참고문헌 | 30편 원문 |
| Domain Track | 18편 | 방사선방호, 의학·당뇨병, AI·검색, 학술 글쓰기 | **역번역 워크북 18편 + 워크북 가이드** |
| Conference Track | 8편 | 국제학회 발표, 슬라이드, 질문 답변, 포스터, 네트워킹 | 패턴·모델 대화·드릴·자기 점검 |
| **합계** | **86편** | **2,372개 학습 문장·표현, 11,907개 청크·표현** | 원문 파일 전체 보존 |

전체 영어 단어 합산(앱 내 계산): 약 36,973단어. 어휘카드 1,197개 항목. **총 109개의 원본 Markdown 문서**를 `source/`에 보관합니다. 두 종류의 원본 문서 형식이 다르므로 Conference Track의 '청크'에는 문장 내부를 임의로 잘라 생성한 청크 대신 **원문에서 추출한 온전한 실전 표현과 대화 문장**을 제공합니다. 원문에 한국어 번역이 없으면 앱이 번역을 만들어내지 않으며 영어만 읽어 줍니다. 모든 원본 표·설명·문헌·연습 자료는 `전체 원본` 탭에서 확인할 수 있습니다.

## 2. 시작하기

- **Windows:** 압축을 푼 뒤 `START_WINDOWS.bat` 실행, 또는 `index.html`을 브라우저에서 엽니다.
- **macOS / Linux:** `bash START_MAC_LINUX.sh`, 또는 `index.html` 직접 실행.
- **직접 로컬 서버:** Python이 있다면 패키지 설치 없이 `python -m http.server 8000` → `http://localhost:8000`.
- **GitHub Pages:** 아래 배포 절차 참조. Node.js, uv, npm, Python 패키지는 사이트 운영에 필요하지 않습니다.

접근 비밀번호: **`redpass`**. 이전 버전의 브라우저 학습 기록은 동일한 저장 키를 유지하므로 같은 도메인에서 업그레이드하면 원칙적으로 계속 사용할 수 있습니다. 만일의 경우를 대비해 먼저 `설정 → 학습 기록 백업`으로 JSON을 저장하는 것을 권장합니다.

## 3. GitHub Pages 배포

1. GitHub 저장소를 준비합니다.
2. 이 ZIP을 풀어 `index.html`, `app.js`, `styles.css`, `content.js`, `service-worker.js`, `manifest.webmanifest`, `assets/`, `source/` 등을 **저장소 최상위**에 업로드합니다. ZIP 한 개만 업로드하는 방식이 아닙니다.
3. 저장소의 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. Branch `main`, Folder `/(root)`를 선택한 뒤 저장합니다.
5. 공개된 HTTPS Pages 주소로 접속해 `redpass`를 입력합니다.
6. 이전 버전에서 업데이트한 경우 먼저 새로고침합니다. 변경 내용이 보이지 않으면 `Ctrl+Shift+R` 강력 새로고침 또는 해당 사이트의 기존 서비스 워커/캐시를 초기화해 주세요. v1.2는 새 PWA 캐시 버전을 사용합니다.

상대 경로를 사용하므로 `username.github.io/repo-name/` 형태의 프로젝트 페이지에서도 동작합니다.

## 4. 86편 연속 듣기 사용법

대시보드 또는 학습 목록 위쪽에서 **연속 듣기** 패널을 열고 재생 범위를 선택합니다.

- **Core 30편:** `01` ~ `30`
- **University 30편:** `U01` ~ `U30`
- **Domain 18편:** `D01` ~ `D18`
- **Conference 8편:** `C01` ~ `C08`
- **기존 60편:** Core 30편 → University 30편
- **전체 86편:** Core → University → Domain → Conference (각각 번호순)

각 청크/문장이 끝나면 다음 항목으로 자동 넘어가고, 마지막 청크가 끝나면 다음 학습편으로 자동 넘어갑니다.

### 연속 듣기 배속 조절 (v1.2 신규)

**0.5배속부터 2.5배속까지, 0.1배속 간격**으로 선택할 수 있습니다.

1. 시작 전: 연속 듣기 패널의 **연속 듣기 속도** 선택창을 이용합니다.
2. 듣는 중: 화면 아래에 나타나는 재생 컨트롤의 **속도 선택창** 또는 **− / + 버튼**으로 조절합니다.
3. 재생 중 속도를 바꾸면 현재 읽고 있는 청크를 새 배속으로 **처음부터 다시 읽습니다.** 일시정지 중 변경하면 설정만 저장하고, 새 배속은 **다음 낭독 항목에 적용**됩니다.
4. 변경한 배속은 개별 듣기·30편·60편·86편 듣기에 동일하게 적용되고 브라우저에 저장됩니다.
5. **영어 후 한국어 번역 듣기**를 선택하면 `영어 청크 → 한국어 번역 → 다음 영어 청크` 순서로 재생됩니다. 해당 한국어 번역이 없는 표현은 영어만 재생합니다.
6. **낭독 항목 화면 중앙 자동 스크롤**을 선택하면 현재 청크나 문장을 강조 표시하고 화면 중앙으로 이동합니다. 자동 이동은 설정에서 해제할 수 있습니다.

재생기는 이전 편, 다음 편, 일시정지/계속 듣기, 정지, 현재 편·청크 위치·전체 진행률을 제공합니다. 다른 메뉴/모드로 수동 이동하면 연속 재생이 정지합니다.

> **기기 제약:** 재생은 실제 녹음 MP3가 아닌 **Web Speech API 기반 브라우저 TTS**입니다. 사용 가능한 한국어·영어 음성은 브라우저 및 운영체제 설정에 의존하고, 휴대폰 잠금 화면/백그라운드 재생은 보장되지 않습니다. 장시간 청취 시 웹페이지를 전면에 두고 화면을 켜 두는 것이 더 안정적입니다.

## 6. GitHub Pages 비밀번호의 중요한 한계

`redpass`는 **클라이언트에 구현된 간단한 화면 접근 확인**에 불과합니다. GitHub Pages의 공개 저장소에 있는 `content.js`, `source/**/*.md`, HTML/JS 파일은 로그인 화면을 건너뛰고 직접 조회할 수 있습니다. 비밀번호 해시가 포함된 JavaScript를 분석해 화면 잠금을 우회하는 것도 가능합니다.

**진정한 회원 전용 콘텐츠 보호**를 하려면 서버측 인증/인가와 보호된 스토리지가 필요합니다. 민감한 자료나 비공개 저작물은 이 구성으로 공개 배포하지 마세요.

## 8. 검증 기록

- 자료 무결성: 원본 기존 60편 + Domain 18편 + Conference 8편 = **86편**, 원본 MD **109개**를 확인했습니다.
- JavaScript 구문 검사는 `node --check app.js`와 `node --check content.js`로 확인했습니다.
- Chromium의 DOM 기반 브라우저 동작 테스트에서 로그인, 4개 트랙 표시, Domain 18편 듣기, Conference 8편 표현 표시, 한국어 번역 순차 낭독, 재생 중 **1.4→1.5→1.2배속 변경**, 워크북 탭, 기존 60편·전체 86편 선택, 390px 모바일 화면에서 가로 넘침 여부를 확인했습니다. 실제 TTS는 테스트용 가상 음성엔진으로 검증했습니다.
- 외부 의존성(CDN·NPM·서드파티 폰트)을 요구하지 않습니다.
