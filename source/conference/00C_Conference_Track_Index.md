# Conference Track · 3단계 학회 말하기 (목차와 사용법)

1–2단계가 **읽고 쓰는 학술 영어**를 다졌다면, 3단계는 학회 현장에서 **듣고 말하는 영어**를 다룹니다. 발표, 질의응답, 청중으로서의 질문, 좌장, 포스터 세션, 네트워킹까지 학회에서 실제로 마주치는 상황을 여덟 모듈로 나눴습니다. 진행 중인 "상황별 패턴 영어" 프로젝트의 학회 편으로 바로 쓸 수 있도록, 모든 모듈을 **상황 → 패턴 → 모델 대화 → 드릴 → 점검**의 같은 구조로 만들었습니다.

## 설계 근거

학회 영어는 문법 지식보다 **바로 꺼내 쓸 수 있는 정형 표현(formulaic sequences)**에 크게 의존합니다. 정형 표현은 통째로 기억에서 꺼내 쓰므로 말하는 동안 처리 부담을 줄여 주고(Wray, 2002), 학습자가 정형 표현을 많이 쓸수록 듣는 사람이 말하기 능력을 더 높게 평가한다는 연구도 있습니다(Boers 외, 2006). 그래서 이 트랙은 표현을 **패턴 단위**로 제시하고, 자기 연구 내용으로 바꿔 말하는 치환 드릴을 중심에 두었습니다.

## 각 모듈의 구성

| 부분 | 내용 | 사용법 |
|---|---|---|
| 1. 상황 | 어떤 장면에서 무엇이 필요한가 | 읽고 시작 |
| 2. 핵심 패턴 | 패턴, 쓰임, 예문 (12–16개) | 예문을 소리 내어 3회씩 |
| 3. 모델 대화·독백 | 패턴이 실제로 쓰인 오리지널 장면 (영·한 대역) | 섀도잉 3회 → 한국어만 보고 말하기 |
| 4. 드릴 | 치환 연습 + 반응 연습 (예시 답안 포함) | 녹음하며 말하기 |
| 5. 자주 하는 실수 | 한국어 화자에게 흔한 표현 오류 | 녹음 들으며 점검 |
| 6. 자기 점검 | 모듈별 체크리스트 | 녹음 후 표시 |

## 4주 진행 계획 (하루 약 30분)

| 주 | 모듈 | 마무리 과제 |
|---|---|---|
| 1 | C01, C02 | 자기 연구로 3분 발표 원고 작성 → 녹음 |
| 2 | C03, C04 | 예상 질문 10개 작성 → 질문을 듣고 즉답하는 녹음 |
| 3 | C05, C06 | 다른 사람 발표 영상(학회 공개 영상 등)을 보고 질문 3개 만들기 |
| 4 | C07, C08 | 1분 연구 소개(엘리베이터 피치) + 후속 이메일 작성 |
