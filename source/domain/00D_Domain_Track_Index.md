# Domain Track · 목차 (18편)

University Track에서 익힌 학술 영어를 **연구 논문의 실제 절(section)**로 옮기는 단계입니다. 각 편은 그 자체가 연구 논문의 한 절(서론, 방법, 결과, 논의 등)이며, 세 분야를 번갈아 다룹니다.

- **RP** 방사선 방호·선량 평가
- **EN** 내분비학·임상 데이터
- **ML** 기계학습·LLM 평가

모든 글은 **가상 연구**를 소재로 한 오리지널 텍스트입니다. 배경 지식은 실제 문헌에 근거하고 참고 문헌을 붙였으며, 연구 설계와 결과 수치는 연습용으로 설정했습니다. 형식은 이전 트랙과 같습니다(원문 → 1회차 청크 → 2회차 문장 → 학술 영어 포인트 → 어휘장 → 낭독 기록표). 분량은 실제 논문 절의 관례를 따릅니다. 서론·방법·논의는 약 330–450단어, 수치가 밀집된 결과 절은 약 250–300단어입니다. Unit E는 장르 관례를 따라 초록·투고 서신·쉬운 말 요약은 약 250–300단어, 심사 답변서는 약 350단어, 발표 원고는 약 4분(약 400단어), 종합편은 약 500단어입니다.

## 다른 트랙과의 연계

University Track 역번역 워크북(WU01–WU30)을 주 2편씩 병행하는 기간에 Domain Track을 함께 진행하도록 설계했습니다. University Track이 학술 문체 일반을 다진다면, Domain Track은 그것을 논문의 각 절이 요구하는 구체적 관례로 좁혀 줍니다.

## 역번역 워크북

Domain Track 18편도 역번역 워크북(WD01–WD18, 총 301문장)으로 만들어 함께 묶었습니다. 형식과 채점 기준은 `00W_Backtranslation_Guide.md`와 같습니다. 각 편의 원문을 2–3회 낭독한 뒤 해당 워크북을 풀면, 논문 문장을 직접 만들어 보는 연습이 됩니다. 특히 D13(초록), D14(투고 서신), D15(심사 답변)의 워크북은 실제 원고를 쓸 때 그대로 응용할 수 있는 문장이 많습니다.
